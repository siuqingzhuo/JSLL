# 军事理论模拟题库

结合《大学生军事理论（第二版）》（薛高连、张冬梅主编）复习表格和 Word 资料制作的离线练习网页。

下载 `index.html`，双击即可在浏览器中使用，无需安装或启动服务器。

## 题库与功能

- 共 435 道客观题：单选 206、多选 129、判断 100。
- 合并 Excel 的 350 道客观题与 Word 新编的 85 道题；重复考点合并处理。
- Word 的 90 个标红段落均有选择题覆盖，共对应 76 道选择题。
- 可以选择章节、题型和题量；题目顺序随机，选择题选项可以随机。
- 自动判分、答案解析、来源查看、错题复习与本浏览器进度保存。
- 多选题须完全选对，漏选、多选、未答均为 0 分；每题 1 分。
- 不包含简答题、论述题。

本版本暂不包含新文件导入或 AI 自动出题功能。

## 保存记录

进度、错题和最近成绩保存在当前浏览器的本地存储中，不上传 GitHub。移动文件、换浏览器或清理浏览数据可能导致旧记录不可用。

资料用于个人复习，不等于学校官方完整考试原题库。遇到教材版本或课程口径差异，请以授课教师要求为准。

## 验证情况

已检查 100 次随机组卷、全部 435 道题的答案和多选精确计分、进度数据校验；网页不依赖外部脚本或网络资源。未完成浏览器实际交互点测。

此仓库提供源文件下载，未启用 GitHub Pages 在线托管。
